# Invitación pirata V2

Esta versión añade una apertura cinematográfica:
1. Pantalla "Prepárate para zarpar".
2. Botón para abrir.
3. Mapa animado.
4. Entrada a la invitación.
5. Cartel tipo recompensa.
6. Cuenta regresiva.
7. Datos del evento.
8. Google Maps.
9. Galería.
10. Confirmación por WhatsApp.
11. Música activada por el usuario.

## Editar
Abre `script.js` y cambia solamente el objeto `invitacion`.

## Fotos
Coloca:
- assets/images/portada.jpg
- assets/images/foto1.jpg
- assets/images/foto2.jpg
- assets/images/foto3.jpg

## Música
Coloca `assets/audio/musica.mp3`.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main; Folder: / (root).
6. Save.
